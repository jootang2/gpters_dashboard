내가 만든 에이전트를 넣어보세요

    

      실습 폴더의 .claude/agents/ 안 .md 파일들과 CLAUDE.md를 통째로 끌어다 놓으세요.
      파일은 어디로도 전송되지 않습니다 — 이 브라우저 안에서만 읽고 끝납니다. 인터넷을 꺼도 됩니다.
    

    
    

      
1단계 export 폴더 만들기

      

        .claude/ 는 점(.)으로 시작하는 숨김 폴더라 브라우저가 열어보지 못합니다.
        아래 한 줄을 Claude Code에 붙여넣어, 숨김이 아닌 폴더로 복사시키세요.
      

      

        
.claude/agents/ 안의 모든 .md 파일과 루트의 CLAUDE.md 를
이 폴더 바로 아래 export/ 폴더에 그대로 복사해줘.
내용은 하나도 바꾸지 말고 원본 그대로. 다 되면 파일 목록만 보여줘.

        
      

    


    
    

      
2단계 export 안의 .md 파일을 전부 넣기

      

        
📄📄📄

        
클릭해서 파일 고르기  ·  또는 파일들을 끌어다 놓기

        

          클릭 → export 폴더 열기 → Ctrl+A(Mac은 Cmd+A)로 전부 선택 → 열기

          폴더가 아니라 파일을 넣어야 합니다 — 폴더는 브라우저가 열어보지 못합니다
        

        
      

      

        ⚠ .md 파일을 찾지 못했습니다.

        폴더를 넣으신 건 아닌가요? 폴더 말고 그 안의 .md 파일들을 직접 선택해야 합니다.

        드롭존을 클릭 → export 폴더로 들어가 → Ctrl+A 로 전부 선택 → 열기.

서브에이전트에이전트 팀

정체한 세션 안의 작업자각각이 독립된 Claude Code 세션

      
서로 대화✕ 불가 — 관제탑에만 보고✓ 팀원끼리 직접 메시지
